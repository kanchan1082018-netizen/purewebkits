Complete User Guide to the 7-Bit ASCII Table, Control Codes, and Character Encodings

How Standard 7-Bit ASCII Maps Characters to Numbers (0–127)

The American Standard Code for Information Interchange (ASCII) assigns each of 128 standard characters a unique 7-bit integer from 0 to 127 (0x00 to 0x7F in hexadecimal). Because ASCII forms the foundational subset of UTF-8 and modern text encodings, developers, network engineers, and students regularly check ASCII decimal, hexadecimal, octal, binary, and HTML entity representations when debugging protocols, escape sequences, CSV/line-ending delimiters (CR/LF), and string parsers. A browser-based ASCII Table Viewer lets you filter all 128 codes and inspect any string's byte codes 100% locally in your browser—with zero server uploads.

Key ASCII Case & Digit Offsets

ASCII arranges digits and uppercase/lowercase Latin letters in contiguous blocks with clean bit patterns:

Digits '0'–'9': Dec 48–57 (0x30–0x39)  |  Uppercase 'A'–'Z': Dec 65–90 (0x41–0x5A)
Lowercase 'a'–'z': Dec 97–122 (0x61–0x7A)  |  Case Offset: 'a' − 'A' = 32 (0x20, single bit)

Helpful Tips When Working With ASCII Codes

  • Watch Line Endings Across Operating Systems: Unix/macOS text files typically use LF (Decimal 10, 0x0A), whereas Windows uses CRLF (13 followed by 10).
  • Remember ASCII Covers 0–127 Only: Accented characters, emojis, and non-Latin scripts (like Devanagari) reside above 127 in Unicode / UTF-8 rather than 7-bit ASCII.
  • Use HTML Entities in Markup When Escaping Reserved Symbols: Characters like < (<), > (>), and & (&) prevent HTML parsing ambiguity.

Worked Example: Typing Hello! into the text inspector displays decimal ASCII codes 72 101 108 108 111 33 and hexadecimal codes 0x48 0x65 0x6C 0x6C 0x6F 0x21.
