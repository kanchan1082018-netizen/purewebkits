How PDF /Info Dictionary Metadata, Author Signatures & Privacy Stripping Work

Why Removing Hidden Author Names and Software Signatures Matters

When you export or convert a document into a PDF using software like Microsoft Word, Adobe Acrobat, LaTeX, or Google Docs, the application automatically embeds an internal PDF /Info dictionary containing metadata such as the author's real name, computer username, software version, creation timestamp, and modification history. If you submit academic research for blind peer review, share a confidential legal brief, or publish an anonymous report, leaving this metadata intact reveals your identity and editing tools. Our browser-based PDF Metadata Editor inspects and strips these tracking fields instantly without modifying body text or vector graphics.

PDF /Info Dictionary Object Formula + Worked Example

Under the ISO 32000 PDF specification, document metadata is stored as an indirect dictionary object containing standard keys:

/Info << /Title (...) /Author (...) /Subject (...) /Creator (...) /Producer (...) /CreationDate (...) >>

Worked Example: Suppose an exported research PDF contains /Author (Jane Doe) /Creator (Microsoft Word 365).

Clicking Wipe All Author & Creator Tags clears those string entries from the /Info dictionary and re-encodes the file via pdf-lib—ensuring zero author footprints remain in the document properties.
