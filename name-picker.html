Complete User Guide to the Random Name Picker, Fisher–Yates Crypto Shuffle & Team Generator

How Unbiased Fisher–Yates Shuffling & Hardware Randomness Work

Whether you are selecting giveaway winners from a social media comment export, calling on students in a classroom, assigning code reviewers, or splitting participants into balanced breakout groups, a fair draw requires sampling without replacement using an unbiased shuffle algorithm. Naive sorting tricks (such as sorting with random floating-point offsets) introduce subtle ordering bias; instead, this tool implements the Fisher–Yates (Knuth) shuffle powered by the browser's hardware-backed window.crypto.getRandomValues() with rejection sampling to eliminate modulo bias. Every permutation of N participants is mathematically equiprobable (1 / N!), ensuring every name in your list has an exact 1 / N probability of being picked first. A browser-based Random Name Picker runs 100% locally in your browser—with zero server uploads.

How to Pick Random Winners or Generate Teams in 3 Easy Steps

  1. Paste or Type Participant Names: Enter names one per line (or comma-separated) in Participant Names—click Remove Duplicates if you want each person entered strictly once, or leave duplicate lines in place for weighted raffle tickets.
  2. Choose Draw Winners or Team Generator Mode: Stay in Draw Random Winners and set Number of Winners to Draw (plus whether to automatically remove drawn winners from the pool), or switch to Random Team Generator to divide participants evenly across N teams.
  3. Run the Draw & Export Results: Click Pick Random Winner (or Generate Random Teams) to reveal the animated selection, then export via Copy Results or Download .txt.

Hypergeometric Draw Odds & Balanced Team Size Formulas

When drawing k distinct winners without replacement from N participants:

Single-Winner Probability = 1 / N  |  Multi-Winner Inclusion Odds (k draws) = k / N
Balanced Team Size = floor(N / T) or ceil(N / T) across T teams

Helpful Tips for Giveaways, Raffles & Classroom Draws

  • Use "Remove Drawn Names From Pool" for Multi-Round Giveaways: When awarding 1st, 2nd, and 3rd prizes one at a time, selecting Remove Drawn Names From Pool ensures nobody wins twice across rounds.
  • Paste Directly From Spreadsheets or CSV Columns: Copying a column from Excel or Google Sheets pastes one name per line cleanly into the input box.
