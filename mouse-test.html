Complete User Guide to Mouse Polling Rate (Hz), Report Intervals & Pointer Smoothness

How Mouse Polling Rate (Hz) and Report Interval (ms) Work

A mouse's polling rate—measured in Hertz (Hz)—is how frequently the mouse reports its position and button state to the computer each second. A 125 Hz office mouse reports once every 8.0 ms, a 500 Hz mouse reports every 2.0 ms, and a 1000 Hz gaming mouse reports every 1.0 ms (with high-polling mice reaching 2000 Hz, 4000 Hz, or 8000 Hz). When testing inside a web browser, pointer motion events (pointermove / mousemove) are delivered through the browser's event loop and display compositor—meaning if you move the cursor slowly or your monitor has a 60 Hz refresh rate, measured browser event frequency may look lower than your hardware's USB/wireless polling setting. Moving the mouse steadily and briskly across the capture pad produces tighter, more representative report intervals. A browser-based Mouse Polling Rate Test measures intervals 100% locally in your browser—with zero server uploads.

Polling Frequency & Report Interval Conversion Formula

Polling rate in Hertz and report interval in milliseconds are reciprocals:

Polling Rate (Hz) = 1000 / Interval_ms  |  Report Interval (ms) = 1000 / Polling_Rate_Hz
Rolling Average Hz = 1000 / Mean_Interval_ms

Helpful Tips for Accurate Polling & Smooth Pointer Testing

  • Use Steady, Continuous Motion Rather Than Tiny Wiggles: Sustained sweeping motion generates a clean stream of motion samples with fewer idle gaps.
  • Remember Display Refresh Rate & OS Settings: If your OS or browser throttles pointer events to screen vsync, a 60 Hz monitor caps standard event rates near 60 Hz while a 144 Hz / 240 Hz monitor allows higher-frequency updates.
  • Check Wireless Dongle Interference: If a wireless gaming mouse shows erratic intervals or drops, moving the USB receiver closer to the mousepad via a short extension cable often stabilizes report consistency.

Worked Example: If consecutive pointer updates arrive every 4.0 ms on average (0.004 seconds), the corresponding report rate is 1000 / 4.0 = 250 Hz; at 1.0 ms intervals, the rate is 1000 / 1.0 = 1000 Hz.
