How Multi-Size Favicons, Binary .ICO Containers & Apple Touch Icons Work

Why Modern Websites Need Both favicon.ico and High-DPI PNG Icons

A favicon (favorite icon) is the small brand emblem displayed in browser tabs, bookmark bars, Google mobile search snippets, and smartphone home-screen shortcuts. While a classic root-level /favicon.ico file remains essential because desktop browsers and search crawlers automatically request it, modern mobile operating systems and Progressive Web Apps (PWAs) require dedicated high-resolution PNG assets: 180×180 px for iOS Safari apple-touch-icon home shortcuts, and 192×192 px plus 512×512 px for Android Chrome and Google Search results. Our generator renders crisp anti-aliased icons at every standard resolution and packs dual 16×16 and 32×32 PNG frames into a valid binary .ico container directly inside your browser.

Binary .ICO Directory Offset Formula & Worked Example

A standard Windows/Web .ico file starts with a 6-byte ICONDIR header followed by 16-byte ICONDIRENTRY records for each embedded resolution:

ICO Header Size = 6 bytes + ( 16 bytes × Number of Embedded Icon Sizes )

Worked Example: When embedding 2 resolutions (16×16 and 32×32) into favicon.ico:

Header + Directory Table = 6 + (16 × 2) = 38 bytes.

The 16×16 PNG payload begins at byte offset 38, and the 32×32 PNG payload immediately follows—allowing every browser to pick the sharpest icon for standard or Retina displays.
